### Chi sono

> **Costruisco sistemi AI che superano la demo e restano in produzione.**

Junior AI Solutions Engineer in **EnerNext** (Oderzo), base a **Treviso**. Lavoro su estrazione di documenti con LLM, pipeline dati e web app Python e TypeScript per EnerNext ed Espiù: bollette, visure, prezzi dell'energia, un accumulo a batteria.

### Come lavoro

<table>
<tr>
<td width="33%" valign="top">

**01 · Un'approvazione umana dove serve**

Niente finisce sul gestionale, sul bus Modbus o in una mail al cliente senza un passaggio che una persona può vedere e fermare. Il modello propone, la responsabilità resta a chi approva.

</td>
<td width="33%" valign="top">

**02 · Parto dai dati veri**

Bollette scansionate, portali senza API dietro un captcha, prezzi che cambiano formato, letture con buchi. La pipeline nasce sui file di produzione, non su un campione pulito.

</td>
<td width="33%" valign="top">

**03 · Consegno cose che si mantengono**

Test che girano senza rete, CI su ogni pull request, deploy automatico, un README che dice il perché delle scelte. Chi arriva dopo deve poter intervenire senza chiedermelo.

</td>
</tr>
</table>
